====================================================================
      MOUNTAIN MULTIMEDIA SERVICE - DOCKER DEPLOYMENT GUIDE
====================================================================

--------------------------------------------------------------------
STEP 1: BUILD & PUSH DOCKER IMAGE (Run on Local Mac Machine)
--------------------------------------------------------------------
Execute in your local project terminal:

docker buildx build --platform linux/amd64 -t jisagarcha/mountain-multimedia:latest --push .


--------------------------------------------------------------------
STEP 2: PULL & LAUNCH CONTAINER (Run on VPS Server Terminal)
--------------------------------------------------------------------
Execute on your Linux server:

docker pull jisagarcha/mountain-multimedia:latest
docker stop mountain-multimedia-web 2>/dev/null || true
docker rm mountain-multimedia-web 2>/dev/null || true
docker run -d \
  --name mountain-multimedia-web \
  --restart unless-stopped \
  --env-file .env \
  -p 3001:3000 \
  -v ./data:/app/data \
  jisagarcha/mountain-multimedia:latest


--------------------------------------------------------------------
STEP 3: FIRST-TIME DATABASE & ADMIN PROVISIONING (On Server)
--------------------------------------------------------------------

curl -X POST http://127.0.0.1:3001/api/auth/sign-up/email \
  -H "Content-Type: application/json" \
  -H "Origin: http://134.209.3.139:3001" \
  -d '{"email":"admin@mountainmultimedia.com","password":"AdminPassword123!","name":"Admin User"}'


2. Populate All Services Catalog Data (10 Categories, 46 Subcategories, 131 Products):

docker exec -i mountain-multimedia-web node -e '
const Database = require("better-sqlite3");
const fs = require("fs");
const db = new Database("/app/data/app.db");
const sql = fs.readFileSync("/app/seed.sql", "utf8");
const stmts = sql.split(";").filter(s => s.trim().length > 0);
for (const s of stmts) { try { db.exec(s + ";"); } catch(e) { console.error(e.message); } }
const c = db.prepare("SELECT COUNT(*) as n FROM categories").get();
const s2 = db.prepare("SELECT COUNT(*) as n FROM subcategories").get();
const p = db.prepare("SELECT COUNT(*) as n FROM products").get();
console.log("Seeded:", c.n, "categories,", s2.n, "subcategories,", p.n, "products");
'
